## 프로젝트 소개

UI/UX 디자인, 그래픽 디자인, 모션 디자인과 웹 퍼블리싱 작업을 모은 개인 포트폴리오입니다. 화면을 디자인하는 과정과 웹으로 구현한 결과를 함께 보여주고자 구성했습니다.

개인 작업은 분야별로 살펴볼 수 있고, 팀 프로젝트는 담당 역할과 작업 과정, 협업하며 배운 내용을 상세 화면에서 확인할 수 있습니다. HTML, CSS, JavaScript를 기반으로 제작하고 GitHub Pages로 배포했습니다.

## 구현한 기능

- **작업물 필터링**: 전체, 그래픽·UI 디자인, 모션 디자인, 웹 퍼블리싱으로 작업을 분류하고 관련 콘텐츠를 표시합니다.
- **상세 모달**: 이미지, 설명과 사용 도구를 확인하고, 작업에 따라 홈페이지와 원본 이미지로 이동할 수 있습니다.
- **영상 재생**: 영상 작업은 상세 화면에서 재생·일시정지와 음량을 조절할 수 있도록 구성했습니다.
- **팀 프로젝트 뷰어**: 프로젝트별 디자인 자료를 넘겨보고, 담당 역할과 협업 경험을 함께 확인할 수 있습니다.
- **반응형 탐색**: 화면 크기에 맞춰 메뉴와 레이아웃을 전환하고, 모바일의 역량·작업물 목록은 가로로 넘겨볼 수 있도록 구성했습니다.
- **스크롤 인터랙션**: 섹션 이동, 콘텐츠 등장 효과와 고정된 Top 버튼으로 페이지 탐색을 연결했습니다.

## 작업하며 다듬은 부분

**모바일에서 읽기 편한 흐름**  
소개글과 작업 설명을 원하는 위치에서 읽을 수 있도록 모바일의 강제 세로 섹션 전환을 해제했습니다. 역량·작업물 카드의 가로 슬라이드는 유지하고, PC의 마우스 환경에서는 섹션 전환을 사용할 수 있도록 적용 조건을 나눴습니다.

**영상 비율과 제목 정리**  
모바일 인트로 영상은 원본 비율로 표시하고, 헤더와 하단 안내에 가리지 않도록 여백을 조정했습니다. 섹션 시작 번호와 소개 영역의 중복 라벨을 정리하고, 영문 섹션명은 Orbitron 14px로 맞췄습니다.

**작업 데이터와 화면 동작 분리**  
개인 작업과 팀 프로젝트 데이터를 나누어 관리하고, 화면에 표시하는 로직은 공통 스크립트에 구성했습니다. 작업 정보를 수정하거나 추가할 때 콘텐츠와 화면 동작을 구분해서 확인할 수 있도록 정리했습니다.
